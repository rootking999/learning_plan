# 第1周：Python编程基础和数学预备知识

## 学习目标
本周的目标是巩固Python编程基础并掌握机器学习所需的数学知识，为后续学习打下坚实基础。

## 学习内容

### 1. Python基础语法复习
- 变量、数据类型、控制结构
- 函数和模块
- 面向对象编程（类和对象）

### 2. 数学基础
- 线性代数基础（向量、矩阵运算）
- 微积分基础（导数、偏导数）
- 概率论基础（概率分布、期望、方差）

## 学习资源
1. 《Python编程：从入门到实践》
2. Khan Academy线性代数课程
3. 3Blue1Brown的微积分和线性代数视频系列

## 时间安排
- 每天学习2小时，共14小时
- 建议前3天重点学习Python，后4天重点学习数学基础
