# 第4周：深度学习入门

## 学习目标
本周的目标是掌握神经网络的基本原理和深度学习框架的使用，为构建复杂的AI系统打下基础。

## 学习内容

### 1. 神经网络基础
- 神经元和激活函数
- 前向传播和反向传播
- 损失函数和优化器

### 2. 深度学习框架
- PyTorch或TensorFlow基础
- 构建简单的神经网络
- 训练和评估模型

### 3. 计算机视觉基础
- 卷积神经网络(CNN)概念
- 图像处理基础
- 经典CNN架构简介

## 学习资源
1. 《深度学习》（Ian Goodfellow等）
2. PyTorch官方教程 或 TensorFlow官方教程
3. CS231n课程（卷积神经网络）

## 时间安排
- 每天学习2小时，共14小时
- 建议前2天学习神经网络基础，中间3天学习深度学习框架，后2天学习计算机视觉基础
