# 第5周：自然语言处理基础

## 学习目标
本周的目标是掌握自然语言处理的基本概念和技术，为构建对话系统打下基础。

## 学习内容

### 1. NLP基本概念
- 文本预处理（分词、词干提取等）
- 词向量表示（One-hot、TF-IDF、Word2Vec）
- 语言模型基础

### 2. 经典NLP任务
- 文本分类
- 情感分析
- 命名实体识别

### 3. 序列模型
- RNN和LSTM基础
- 序列到序列模型
- 注意力机制概念

## 学习资源
1. 《自然语言处理综论》
2. NLTK文档
3..fastText教程
4. 《Speech and Language Processing》

## 时间安排
- 每天学习2小时，共14小时
- 建议前2天学习NLP基本概念，中间3天学习经典NLP任务，后2天学习序列模型
