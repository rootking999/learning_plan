# 第3周：机器学习基础

## 学习目标
本周的目标是掌握机器学习的基本概念和经典算法，为深入学习深度学习打下基础。

## 学习内容

### 1. 机器学习基本概念
- 监督学习、无监督学习、强化学习
- 训练集、验证集、测试集
- 过拟合和欠拟合

### 2. 经典机器学习算法
- 线性回归
- 决策树
- K近邻算法

### 3. Scikit-learn库使用
- 数据预处理
- 模型训练和评估
- 交叉验证

## 学习资源
1. 《机器学习》（周志华）
2. Scikit-learn官方教程
3. Coursera机器学习课程（Andrew Ng）

## 实践任务
- 使用Scikit-learn实现线性回归模型
- 实现决策树分类器
- 完成一个完整的机器学习项目（从数据预处理到模型评估）

## 检查清单
- [ ] 理解机器学习的基本概念和分类
- [ ] 掌握线性回归和决策树算法原理
- [ ] 能够使用Scikit-learn构建和评估模型
- [ ] 理解过拟合和欠拟合的概念及解决方法

## 时间安排
- 每天学习2小时，共14小时
- 建议前2天学习基本概念，中间3天学习经典算法，后2天学习Scikit-learn
