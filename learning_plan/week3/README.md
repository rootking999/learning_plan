# 第3周：机器学习基础

## 学习目标
本周的目标是掌握机器学习的基本概念和经典算法，为深入学习深度学习打下基础。

## 学习内容

### 1. 机器学习基本概念
- 监督学习、无监督学习、强化学习
- 训练集、验证集、测试集
- 过拟合和欠拟合

### 2. 经典机器学习算法
- 线性回归
- 决策树
- K近邻算法

### 3. Scikit-learn库使用
- 数据预处理
- 模型训练和评估
- 交叉验证

## 学习资源
1. 《机器学习》（周志华）
2. Scikit-learn官方教程
3. Coursera机器学习课程（Andrew Ng）

## 时间安排
- 每天学习2小时，共14小时
- 建议前2天学习基本概念，中间3天学习经典算法，后2天学习Scikit-learn
