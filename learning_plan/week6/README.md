# 第6周：语音处理技术

## 学习目标
本周的目标是掌握语音识别和语音合成的基本技术，为构建语音交互系统打下基础。

## 学习内容

### 1. 语音识别基础
- 音频信号处理
- 特征提取（MFCC等）
- 声学模型和语言模型

### 2. 语音合成基础
- 文本到语音转换原理
- 声码器基础
- 语音合成评价指标

### 3. 语音处理工具
- librosa库使用
- 语音识别API（如Whisper、SpeechRecognition）
- 语音合成工具（如gTTS、 pyttsx3）

## 学习资源
1. 《语音与语言处理》
2. librosa文档
3. Whisper模型文档
4. SpeechRecognition库文档

## 时间安排
- 每天学习2小时，共14小时
- 建议前2天学习语音识别基础，中间3天学习语音合成基础，后2天学习语音处理工具
