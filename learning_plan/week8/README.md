# 第8周：知识表示和推理

## 学习目标
本周的目标是掌握知识表示和推理技术，为构建具备知识库的智能助手打下基础。

## 学习内容

### 1. 知识图谱基础
- 图数据库概念
- RDF和OWL基础
- 知识图谱构建流程

### 2. 推理技术
- 基于规则的推理
- 基于图的推理
- 逻辑推理基础

### 3. 信息抽取
- 命名实体识别
- 关系抽取
- 事件抽取

## 学习资源
1. 《知识图谱：方法、实践与应用》
2. Neo4j教程
3. spaCy文档
4. 《知识图谱技术及应用》

## 时间安排
- 每天学习2小时，共14小时
- 建议前2天学习知识图谱基础，中间3天学习推理技术，后2天学习信息抽取
